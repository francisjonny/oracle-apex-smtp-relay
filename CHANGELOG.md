# Cambios

## 1.0.0

- Servicio HTTPS con remitente fijo, clave API protegida y SMTP STARTTLS.
- Idempotencia persistente, límites, validaciones y estados de incertidumbre.
- Configuración privada interactiva y control CLI sin mostrar secretos.
- Ejemplo Oracle independiente: outbox transaccional, Web Credentials y job.
- Guía de instalación en español, contrato API y diagnóstico por capas.
- Pruebas PHP, HTTP y concurrencia sin correos reales.

Los SQL de ejemplo generalizados deben compilarse y probarse en el esquema de
destino. La suite no contiene credenciales ni acceso a Oracle.
